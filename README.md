# خدمني — منصة خدمات طلابية

نسخة Full-Stack قابلة للتشغيل محليًا أو الرفع على استضافة Node.js.

## ما تم ربطه فعليًا
- تسجيل وإنشاء حسابات للمستخدمين بكلمة مرور مشفرة.
- تسجيل دخول JWT.
- قاعدة بيانات SQLite.
- قائمة خدمات حقيقية من قاعدة البيانات.
- تسجيل الطالب كمقدم خدمة وربط الخدمات بحسابه.
- حفظ رقم CliQ لمقدم الخدمة.
- إرسال طلب خدمة إلى مقدم الخدمة وإنشاء إشعار له.
- عرض رقم CliQ لمقدم الخدمة للعميل بعد الطلب.
- متابعة الطلبات وتغيير حالتها.
- لوحة مطور حقيقية مرتبطة بالـ API.
- إدارة الخدمات والمستخدمين والطلبات من لوحة المطور.

## حسابات المطور الافتراضية
- admin@khidmeni.local / khidmeni2026
- developer2@khidmeni.local / khidmeni2026-2
- developer3@khidmeni.local / khidmeni2026-3

غيّر كلمات المرور عند النشر الحقيقي، ولا تستخدم هذه الحسابات كما هي في الإنتاج.

## التشغيل
يتطلب Node.js 20+.

```bash
npm install
```

ثم ضع متغير بيئة قويًا:

```bash
JWT_SECRET="ضع_سرًا_طويلًا_وعشوائيًا_هنا"
```

ثم:

```bash
npm start
```

وافـتح:

`http://localhost:3000`

## مهم بخصوص CliQ
هذه النسخة لا تخصم المال تلقائيًا ولا تتصل ببوابة بنكية. هي تحفظ رقم/معرّف CliQ الذي يضعه مقدم الخدمة وتعرضه للعميل. أي تكامل دفع فعلي يحتاج مزود دفع/بنك وواجهة API واتفاقية تجارية مناسبة.

## قبل الإطلاق على الإنترنت
- استضافة Node.js حقيقية.
- نطاق حقيقي وHTTPS.
- `JWT_SECRET` قوي في متغيرات البيئة.
- تغيير حسابات المطور وكلمات مرورها.
- إضافة سياسة خصوصية وشروط استخدام.
- إضافة حماية معدل الطلبات والتحقق من المدخلات ونسخ احتياطي لقاعدة البيانات.
- تحديث canonical وOpen Graph إلى النطاق الحقيقي.
- إنشاء sitemap وrobots.txt وربط الموقع بـ Google Search Console لبدء الفهرسة.
